## 敬业签核心功能一览

| 功能 | 说明 |
|------|------|
| 云便签 | 文字、图片、视频、音频、文档附件 |
| 待办清单 | 独立的待办事项，可逐条勾选完成 |

| 快捷工具栏 | 底部自定义快捷入口，可启动本地程序 |
| 分类加密 | 对特定分类设置密码保护 |
| 桌面嵌入 | 窗口嵌入桌面，回桌面时不动 |

| AI 功能 | AI 辅助记录 |

## 值得借鉴的点

**Q1: 时间轴（操作日志）**

敬业签的时间轴功能很有价值——所有操作（新增、修改、删除）都永久保存，可以追溯"昨天改了什么"、"上周删了什么"。

对我们便签的意义：
- 误删后可以从时间轴恢复（比回收站更强大）
- 写周报/月报时可以回顾"这周做了什么"
- 类似 git log，但面向普通用户

```
┌─────────────────────────────────────────────┐
│  时间轴                          [筛选 ▼]    │
├─────────────────────────────────────────────┤
│  今天                                        │
│  10:30  修改了「会议记录」                     │
│  09:15  新建了「待办清单」                     │
│                                             │
│  昨天                                        │
│  18:00  删除了「过期通知」                     │
│  14:20  修改了「项目计划」                     │
│  10:00  新建了「购物清单」                     │
└─────────────────────────────────────────────┘
```

答：我觉得可以，然后时间轴也是以列表的形式，在左边列表增加一个入口

**Q2: 日历视图**

在日历上看到哪天创建/修改了便签，点击日期筛选当天的便签。

对我们便签的意义：
- 视觉化的时间管理
- 快速定位"某天的便签"
- 支持月/周两种视图就够了
答：这个没必要，和时间轴功能冲突


**Q3: 分类加密**

对特定分类设置密码保护，比如"账号密码"分类加密。

对我们便签的意义：
- 用户可能用便签存密码、账号等敏感信息
- 加密后查看需要输入密码
- 简单实现：分类级别密码，不看时自动锁定
答：做，增加内置的隐私分组，可以添加到这里，用户可以在设置栏设置隐私分组进入时的密码。

**Q4: 便签内附件**

敬业签支持在便签中添加图片、视频、音频、文档。

对我们便签的意义：
- 当前只支持纯文本，功能单薄
- MVP 可以先支持文件附件（不嵌入，只链接）
- 后续再支持图片内嵌
答：先支持文件链接

**Q5: 待办独立管理**

敬业签的待办是独立模块，和便签分开管理。

对我们便签的意义：
- 现有待办是便签的一种类型，混在一起
- 是否需要独立的待办视图？只看所有待办，不看文字便签
- 这样待办管理更清晰
答：有必要，可以顶部横向做分组，搜索向上，左边一栏点击是便签，右边一栏点击是分组

**Q6: 快捷工具栏**

底部固定一排快捷入口，可以自定义。

对我们便签的意义：
- 可能过于复杂，违背简洁原则
- 但可以考虑：快速访问最近打开的便签
答：没必要暂时，不做

## 不建议借鉴的点

| 功能 | 理由 |
|------|------|
| 微信/钉钉/短信提醒 | 需要第三方集成，复杂度高 |
| 农历支持 | 小众需求 |
| 桌面嵌入 | 我们已有边缘吸附，功能类似 |
| 甘特图视图 | 便签工具不需要项目管理功能 |
| AI 功能 | 我们专注便签，不做 AI |
答：同意

## 我的判断

| 功能 | 推荐 | 理由 |
|------|------|------|
| Q1 时间轴 | **做** | 误删恢复 + 历史追溯，比回收站更强大 |
| Q2 日历视图 | **考虑** | 有用但实现成本较高，可 P2 |
| Q3 分类加密 | **做** | 保护敏感信息，实现简单 |
| Q4 附件支持 | **做** | 便签基础功能，先支持文件链接 |
| Q5 独立待办视图 | **考虑** | 有用，但增加 UI 复杂度 |
| Q6 快捷工具栏 | **不做** | 违背简洁原则 |

**最值得做的三个**：

1. **时间轴** — 所有操作记录永久保存，误删可恢复，写周报可回顾
2. **分类加密** — 保护密码等敏感信息
3. **附件支持** — 便签不只是文字，还能存文件

你觉得哪些值得做？
