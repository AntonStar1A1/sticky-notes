## 一、效率提升类

**Q1: 全局快捷键快速创建便签**

现在的快捷键只在 app 窗口激活时有效。如果用户在浏览器看网页、在 IDE 写代码，想快速记个东西，需要切到便签 app 再新建。

优化：**全局热键**，比如 `Ctrl+Shift+N`，在任何应用中按下都能唤出一个新便签窗口并自动聚焦。
答：可以，最好支持在设置栏用户自定义热键

**Q2: 剪贴板快速创建**

用户复制了一段文字，想存为便签。

优化：**Ctrl+Shift+V** 从剪贴板内容直接创建新便签，省去粘贴步骤。
答：可以，最好支持在设置栏用户自定义热键

**Q3: 便签复制/克隆**

有些便签是模板性质的（比如每日待办清单），每次都要重新建很麻烦。

优化：右键菜单加「复制便签」，创建一个内容相同的新便签。
答：可以
---

## 二、编辑体验类

**Q4: Markdown 支持**

现在便签只支持纯文本。如果支持 Markdown，用户可以写标题、列表、加粗、代码块等。

优化：便签内容支持 Markdown 渲染，编辑时是源码，查看时渲染。
答：没多大必要，记录多为文本，暂时不实现

**Q5: 自动保存状态提示**

现在便签是防抖自动保存的，但用户不知道是否已保存。

优化：标题栏或角落显示一个小圆点，保存中 = 蓝色，已保存 = 绿色/消失。
答：可以

**Q6: 字数统计**

写了很多内容后，想知道有多少字。

优化：状态栏显示字数/字符数（可选，不打扰）。
答：可以，设置栏支持设置是否显示字数/字符数

---

## 三、组织管理类

**Q7: 标签系统**

分类是树形结构，一个便签只能属于一个分类。标签更灵活，一个便签可以有多个标签。

优化：给便签加标签（如 `#工作` `#重要`），搜索时支持 `#标签名` 过滤。
答：没必要，不做

**Q8: 便签置顶到桌面**

现在有「置顶」功能，但只是置顶在便签列表里。如果能置顶到操作系统的最上层，就像桌面便签一样永远可见。

优化：这个功能其实已经有了（`is_pinned` + `setAlwaysOnTop`），确认一下是否好用。
答：已有功能，不再考虑

**Q9: 便签链接**

便签之间可以互相引用，比如「详见会议记录便签」。

优化：输入 `[[便签标题]]` 自动创建链接，点击跳转。
答：不做，实现复杂，且意义不大

## 四、视觉体验类

**Q10: 暗色/亮色主题切换**

现在只有暗色毛玻璃风格。有些用户喜欢亮色。

优化：设置面板加主题切换（暗色/亮色/跟随系统）。
答：可以，同时支持自定义颜色，例如淡蓝色、紫色、黄色；

**Q11: 便签窗口样式**

所有便签窗口长得一样，除了颜色。

优化：支持选择窗口样式（毛玻璃/纯色/渐变），让便签更有个性。
答：可以，展开编辑时支持选择

## 五、提醒与自动化类

**Q12: 便签提醒**

有些便签内容是待办事项，需要提醒。

优化：右键便签 → 设置提醒时间，到时间后弹出系统通知。
答：可以考虑，后续细化后实现，先不实现

**Q13: 定时清理回收站**

回收站里的便签一直占着空间。

优化：设置中加「自动清理回收站超过 X 天的便签」。
答：做，自动清理超过30天的，超过的标为彻底删除，和之前的需求一样，所有删除都是打标记；
另外增加删除方式字段，用户手动清理的，标记来源，超时自动清理的，也标记来源

## 六、我的判断

| 功能 | 推荐 | 理由 |
|------|------|------|
| Q1 全局快捷键新建 | **做** | 便签工具的核心价值就是快速记录 |
| Q2 剪贴板创建 | **做** | 极大提升信息收集效率 |
| Q3 复制便签 | **做** | 实现简单，用户经常需要 |
| Q4 Markdown | **考虑** | 有用，但实现成本较高，可以 P2 |
| Q5 保存状态提示 | **做** | 一行代码的事，给用户安全感 |
| Q6 字数统计 | **不做** | 便签工具不需要这个 |
| Q7 标签系统 | **不做 MVP** | 和分类功能重叠，增加复杂度 |
| Q8 置顶桌面 | **已有** | 确认现有功能好用即可 |
| Q9 便签链接 | **不做 MVP** | 高级功能，后续再考虑 |
| Q10 主题切换 | **不做 MVP** | 暗色风格是特色，暂不改 |
| Q11 窗口样式 | **不做 MVP** | 增加复杂度 |
| Q12 便签提醒 | **考虑** | 有用，但需要系统通知权限 |
| Q13 自动清理 | **做** | 简单配置，保持数据库整洁 |

**MVP 建议做**：Q1 全局快捷键 + Q2 剪贴板创建 + Q3 复制便签 + Q5 保存状态 + Q13 自动清理
