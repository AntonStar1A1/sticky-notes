# 便签应用交付报告 — 2026-08-15(v0.1.2)

## 一、本轮概览

v0.1.1 发布后真机使用反馈驱动的迭代:修复 2 个缺陷(分组无法设置、收起态换行丢失),完成 7 项交互改进(右键菜单、透明度调节、最小化、时间轴等),版本升至 0.1.2 并构建 release 发布包。全部改动经真机逐项确认「没问题」后交付。

## 二、缺陷修复

### 1. 便签无法设置分组(右键后仍留在默认分组)

- **根因**:管理器右键菜单没有「移动到分组」入口;且便签窗口的防抖保存走 `update_note` 整行回写,若在管理器移动分组,已被打开的便签窗口随后保存会把 category_id 整行覆盖回旧值。
- **修复**:
  - 后端新增原子命令 `set_note_category`(单字段 `UPDATE notes SET category_id = ?1` + 时间轴「move」记录 + 标记未同步),沿用 `set_note_pinned` 的防覆盖策略;
  - `db::update_note` 的整行回写 SQL 不再写 category_id(与 is_pinned 同样处理),便签窗口的自动保存无法覆盖管理器侧的分组变更;
  - 前端移动分组走 `invoke('set_note_category')`,乐观更新列表。

### 2. 便签窗口收起态换行丢失(多行变一行)

- **根因**:收起态内容区默认 `white-space: normal`,把 `\n` 折叠成空格;数据本身无损,纯显示问题。
- **修复**:`.compact-summary` 设 `white-space: pre-wrap`,换行原样保留。

### 3. 设置「关于」页版本号停留在 0.1.0(发布后追加)

- **根因**:版本号在前端硬编码 `0.1.0`,升级版本时只同步了 tauri.conf/Cargo/package 三处,漏掉前端文案。
- **修复**:改为 `getVersion()` 运行时读取编译进二进制的 tauri.conf.json 版本,此后升级无需再手工同步前端;release 包已重新构建。

## 三、交互改进

1. **右键菜单「移动到分组」就地展开**:先做同级平铺(分组多时菜单过长),再做侧边飞层(280px 管理台放不下、与父级割裂),最终定为点击展开的折叠列表——紧贴父级菜单、整体限高 300px 滚动、长分组名省略号,分组前 ✓ 标记当前所在。
2. **右键菜单底部锚定跟随鼠标**:改为 CSS bottom 锚定(菜单底边贴鼠标 - 4px),下方空间不足时菜单向上生长、展开分组列表也向上生长,彻底解决「卡在管理台中间/悬在鼠标上方」的定位漂移。
3. **收起态不截断内容**:去掉 4 行行数截断与「还有 N 项」,内容与待办全部可见、超出上下滚动。
4. **透明度改 Ctrl+滚轮**:普通滚轮保留给收起态滚动与正文滚动,Ctrl+滚轮以 0.05 步进调节 0.15–1.0,并 preventDefault 拦下 WebView 的 Ctrl+滚轮缩放。
5. **便签窗口新增「─ 最小化」按钮**:收起/展开态头部、关闭按钮旁,直接最小化到任务栏。
6. **移除右键菜单无效「颜色」项**:点击无响应;改色保留在便签卡片上的调色板按钮。
7. **时间轴内容修改展示具体内容**:后端 `update_note` 的 changes 记录 `content: { old, new }` 真实文本(此前为占位文字);前端红/绿两行对比展示,各最多 3 行省略。
8. **时间轴分页导航换行**:页码多时 `flex-wrap: wrap`,分页按钮换到下一行,不再挤占「每页 N 条」选择器。

## 九、已知限制(继承 v0.1.1)

- 右键菜单「移动到分组」就地展开,分组很多时依赖菜单内滚动(限高 300px),暂无搜索;
- 时间轴内容对比每行最多显示 3 行,超长内容不提供展开;
- 服务器同步(阿里云)仍为规划项,当前为本地 SQLite + sync_queue 离线队列。
